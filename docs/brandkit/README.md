# JuLC Brand Kit

Official brand assets for **JuLC** — Java → UPLC compiler for Cardano smart contracts.
https://julc.dev · https://github.com/bloxbean/julc

## What's inside

- `logo/svg/` — vector logo mark, 8 colorways
- `logo/png/` — raster logo mark, sizes 16–1024px
- `wordmark/` — JuLC. wordmark, SVG + PNG
- `lockup/` — horizontal mark + wordmark lockup, SVG + PNG
- `favicons/` — favicon set (16, 32, 48, 180, 192, 512), light + dark
- `stickers/` — printable sticker artwork (round + die-cut square)
- `tokens/` — color tokens as JSON / CSS / SCSS
- `guidelines.html` — printable brand guidelines (open in browser, print to PDF)

## Palette

| Token   | Hex       | Usage |
|---------|-----------|-------|
| Black   | #000000   | Primary surface, dark mode |
| Ink     | #0B0B0D   | Soft black, UI text |
| Paper   | #FFFFFF   | Light surface, documents |
| Surface | #F5F5F5   | Soft canvas, cards |
| Orange  | #F89820   | Primary accent (Java heritage) |
| Indigo  | #4F46E5   | Secondary accent (UPLC / depth) |

## Typography

- **Display:** Inter Tight (400 / 600 / 800)
- **Mono:** JetBrains Mono (400 / 500 / 700)

## Rules

- Always preserve at least **½X** clear space around the mark, where X is the cap-height.
- Mark scales cleanly to **16px**. Below that, use a solid square fallback.
- **Don't** stretch, rotate, recolor parts, or apply drop-shadows to the mark.
