JuLC.

Java → UPLC. Cardano smart contracts in the language enterprise already knows.

The mark

The JuLC mark is a custom monogram built from a single ribbon outline forming the lambda (λ) of UPLC. Always use the official artwork. Never reconstruct or redraw.

Black on light
White on dark

Lockup

Use the horizontal lockup whenever space allows. The accent dot after JuLC is part of the wordmark.
