# ADR-068 M6: JavaParser is gone

Worktree branch `wip/068-m6`, from `41bee0eb` (PR #267's head `ff94749c` and `JULC0130`). javac is JuLC's only Java reader:
`com.github.javaparser` is on no class path, and a check keeps it so. The compiled bytes did not change: I1 moved 0 rows of
bytes. This document records what was done, what each test became, the harness that replaced the two-frontend comparison, and the
gates at the closing head.

## The harness after M6

- `DiffConfig` is `(level, vm)`. A case compares the JVM with javac at each level. The saved cases, G0 and the G1 fixed seed run as before.
- **I1**: `Adr068LoweringTest` compiles every corpus case and compares its observation with `adr/evidence/068/lowering-javac.tsv`. A row
  is the key, a status, eight cells (each level with and without a source map), diagnostics, `@Param` infos, located terms, each method's
  term, the type registry and the contract's schema or debug metadata. A moved row fails; `allowShrink` is off. `-Padr068.freeze=true`
  writes the table, whose diff a review reads. `Adr068LoweringToolTest` injects a difference into the bytes and the method-term columns and requires the failure; the gate compares each whole line, so a move in any other column fails it too.
- **The reference as data**: `lowering-reference.tsv` and `lowering-i1.tsv` stay as evidence and are never regenerated. The table was written
  in the run at stage 0 where the reference and javac compared, 0 moved. `frozen-reference.tsv` holds the 8,250 answers the lowering tests
  compared with, and `-Pjulc.frozenReference.record=<file>` is how a meant change writes them.
- **G1's policy**: a rejection is a failure, unless `CampaignVerifier.POLICY_REJECTIONS` lists its code with a decision. It holds
  `JULC0078` (D6), a comparison Java keeps distinct. Before M6 a program both frontends accepted could not meet it.
- **Saved cases**: 72 of the `.diffcase` files take their answer on javac, with a note line saying what the JavaParser frontend answered
  ([`rebaselined`](068/m6-rebaselined-diffcases.tsv)): 32 semantic fixes or accepted by decision, 24 policy rejections, 16 changes of a
  diagnostic. None went to a mismatch.
- **Rediscovery**: profiles stay. `REDISCOVER_209`, `_280`, `_146`, `_291` and `_291_LOOPS` pass on javac. `REDISCOVER_162` is not reference-only: ADR-066 designs it as must-reject evidence on the fixed compiler, so it stays with the same meaning, and it ends in `JULC0120` at try 2, the same reassignment of `v1`, at all four levels. It exits 1 by design, as at M5.
- **Retired tasks**: `adr068Baseline`, `adr068Types`, `adr068ContractDebug`, `adr068GateTiming`, `adr068Recheck`, whose questions are columns of
  the table. `adr068Lowering` and `adr068G1Capture` stay.

## Deviations from the ADR (r20)

1. D10 said the harness compares the frontends "while both exist", and D13's five-part comparison ran on two compilers. With one compiler,
   the frozen table is the comparison. The invariant is unchanged: a moved row fails.
2. D12 said `javax.lang.model` for the verification resolvers. M6a proposed syntax trees with today's matching, as a separate later decision
   for identity; the maintainer delegated the wording, and r20 records it.
3. Image sizes (a stated target of M6): measured, full Wasm 37.0 MB at M5 to 33.1 MB (33,114,502 bytes), native CLI 109.5 MB to 97.8 MB (97,768,280 bytes), both with `AbortOnTypeReachable`. Neither returns to its pre-M5 size (24.5 MB and 90.0 MB), since javac and its platform stay in.

## Things found on the way

- `diagnostics.json` at the given head was invalid JSON (`d5c1bd60`); `ExplainDiagnosticToolTest` and any catalog reader failed. This is a
  defect of the head, from `JULC0130`'s commit, and worth a look on PR #267.
- javac's `cannot access <class>` names a class that varies between runs on a repository test file, where a source reaches a class the closed
  platform lacks. Rejected either way; only the words vary. The metadata gate normalizes it. Listed in the follow-ups.
- `JULC0087`'s fix named the way back to the JavaParser frontend. Rewriting it moved 23 rows of the table, only the contract-rejection digest
  (`moved-by-julc0087-fix`), with no bytes; the table was re-frozen, and the metadata gate reads past the two rewritten strings.
- `AGENTS.md` names `SymbolTable.declareMethod`, a class that is gone (`Generated names`). This work did not change the instructions file;
  the rule stands, and the maintainer may wish to point it at `Scope`.
